# Stage 1：用 Claude App 開啟並預覽

## 學員操作

把以下 prompt 貼給 Claude：

> 請先閱讀 README 與 CLAUDE.md，告訴我這個專案如何預覽、會需要哪些動作與權限。現在不要修改任何程式檔。等我確認後，請依專案既有方式準備並開啟 Preview；不要更新套件、不要更改 Firebase Security Rules，也不要存取專案資料夾以外的位置。

## Checkpoint

- Claude 能說出這是未登入、只限合成資料的排班 Demo。
- App Preview 可以開啟。
- `/course-check` 可以開啟。
- Vercel URL 可以開啟。
- Review changes 沒有意外內容。

十分鐘內無法解決就使用 `checkpoint/stage-1`，不要用陌生指令硬闖。
