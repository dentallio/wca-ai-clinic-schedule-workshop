# Stage 3：完成排班核心功能

本階段專注使用與驗收，不展開 Firestore 原理。只使用從零建立的合成情境。

## 手動驗收

1. 切回本週。
2. 點王醫師某個週一空白格，選早診。
3. 點同一格改成午診，確認畫面只有一個班別。
4. 點林醫師某個週三，先排早診再改成休假，確認兩者不會同時存在。
5. 前往下一週新增一格，再回上一週確認兩週資料各自保留。
6. 重新整理頁面，確認以上合成資料仍存在。

## 自動驗收

請 Claude 先說明指令用途，再執行：

```bash
npm run test
```

測試必須涵蓋：

- 空白格新增。
- 同格改班不重複。
- 休假取代班別並移除 `shiftId`。
- 日期跨月、跨年。
- 本機練習模式重新訂閱後仍可讀取。

## Checkpoint

手動六步與自動測試都通過，再建立本階段 commit。卡住時使用 `checkpoint/stage-3`；程式 checkpoint 不會清除 Firestore，但仍應先到 `/settings` 匯出 JSON。
