# Stage 3：完成原版當日排班操作

## 手動驗收

1. 點 7 月任一非週日日期，確認右側開啟當日抽屜。
2. 展開一位標有「AI 建議」的助理並按「確認排班」。
3. 再次展開，測試「換人」後同一人不會重複出現在兩診。
4. 在缺人的診次按「補一名助理」，確認人數立即增加。
5. 將一位未排班人員標記休假，確認排班與休假互斥。
6. 關閉抽屜再開啟，然後重新整理，確認合成資料仍存在。

## 自動驗收

```bash
npm run test
```

測試涵蓋新增／改班互斥、休假取代班別、跨月跨年日期，以及本機資料重新訂閱。

Checkpoint：`checkpoint/original-ui-stage-3`。
